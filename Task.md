# reMagX web application refactoring

## Goal

Refactor reMagX into a complete web application using TypeScript, with WebAssembly for numerical calculations.

## Requested workflow

1. Analyze the existing program first.
2. Then use the brainstorming skill.
3. Document the analysis and brainstorming in `docs/`.

## Requirements

- Browser-local first; shared features can come later.
- Use only double precision for numerical calculations. Do not retain single or extended precision modes.
- Legacy projects must also use double precision, regardless of their saved precision setting.
